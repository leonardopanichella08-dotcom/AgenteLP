La foto viene usata **sia nella scheda della lobby sia come faccia del
personaggio 3D**. Finché il file non esiste, il gioco mostra in automatico un
placeholder cartoon con le iniziali: non serve toccare il codice.
Per usare un'altra estensione (png/webp) cambia il campo `photo` in
`src/game/characters.js`.
